About This Project

Know the purpose and technologies behind Smart Student Planner.

Project Purpose

Smart Student Planner is a frontend web project created to help students organize assignments, project deadlines, and study tasks in a professional and user-friendly interface.

Technologies Used

  • HTML for webpage structure
  • CSS for styling, responsive layout, and visual design
  • JavaScript for dynamic interactivity and Local Storage

Main Learning Outcomes

  • DOM manipulation
  • Event handling
  • Responsive design
  • Local Storage usage
  • Multi-page website linking
