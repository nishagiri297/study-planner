About StudyPlanner

Why it exists, what it does, and how it was built.

The Problem It Solves

Every student has missed a deadline they forgot about — or spent 10 minutes searching through WhatsApp groups for an assignment date. StudyPlanner fixes that. One clean place to add every task, see what's urgent, and track what's done — entirely in your browser with zero accounts or setup required.

What It Does

Add tasks with title, description, deadline, and priority
Color-coded urgency — overdue, today, this week, future
Live progress bar tracking completion percentage
Search and filter tasks by status or priority
Persistent storage — data survives page refresh
Dark mode with auto-remembered preference

Tech Stack

Built entirely with vanilla HTML5, CSS3, and JavaScript — no frameworks, no dependencies, no build tools. Data persistence uses the browser's localStorage API. Deployed via GitHub Pages.
